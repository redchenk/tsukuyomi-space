# Terminal 官方服务每日调用

管理员在 `/terminal?panel=analytics` 的“统计”中查看全站官方 LLM 与官方 TTS 的每日请求，可选择 7、30、90 天和截至日期。统计统一采用北京时间（Asia/Shanghai），今日指标与所选历史时段分别显示。

只读接口 `GET /api/admin/official-usage?days=30&end=2026-10-30` 沿用 Terminal 管理员认证，响应禁止缓存。普通用户和未登录访客无权读取。

数据来自主站持久化的 `billing_requests` 与 `site_wallet_admissions`，覆盖国内、海外及接入同一官方服务的客户端。按唯一请求编号计数，按发起日期归档；`unit=voice` 是 TTS，其余当前官方模型请求是 LLM。免扣费请求同样计入。统计不依赖网页打开、浏览器上报、语音文件缓存或定时任务，历史已保存记录可以直接查询。

- 完成：`settled`，已取得最终用量记录。
- 未完成：`released`，失败或取消并已释放预留。这个数字不代表已消费的供应商请求。
- 待确认：`reserved`、`unknown`、`needs_review`，包括处理中的请求和结果尚未核实的请求。
- 幂等重试、语音缓存回放不会新增请求。用户自带 API、健康探测、授权或余额不足等接纳前拒绝不计入。

请求状态可能在发起日之后更新，因此旧日期的完成／待确认数量也会更新。历史未保存的调用无法补算；“最早记录”表示现存官方请求中最早的一天，不代表功能上线日期。只返回聚合数字，不读取对话、音频、密钥、用户身份或金额，不改动计费和余额。

迁移 `057` 仅为请求创建时间添加索引，现有调用记录继续作为唯一数据来源。
