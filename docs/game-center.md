# 游戏中心与月下五子棋

- `/game`：游戏中心，发现导航、搜索与八千代向导的统一入口。
- `/game/gomoku`：和八千代对弈、实时聊天的五子棋。
- `/game/kaguya-run`：原辉夜快跑。原游戏运行时、沙箱、积分提交和排行榜保持原有实现；每日跑酷任务直接跳转这里。

## 五子棋

采用 15 × 15 自由五子棋：黑棋先行，任意方向连续五子或更多获胜，无禁手。轻松模式使用局势评分，认真模式在候选点上增加有界的应手搜索；两种难度都会优先完成己方五连、阻挡对方立即成五。规则与选点实现位于 `src/frontend/services/games/gomoku.mjs`；规则与选点在本地运行。

实时互动由 `gomokuCompanion.mjs` 复用 Room 的 `requestRoomReply`，沿用现有直连、代理、本地 Ollama 与站内直供会话/计费流程。使用 `shared/room-character.cjs` 的人物卡和 `shared/room-dialogue.cjs` 的对话策略；用户文本不写入系统指令。每次请求携带真实棋盘（双方颜色、落子、轮次、胜负、提示位置），支持自由输入、快捷发言、流式回复、停止与重试。模型负责对话，实际落子与胜负由棋盘引擎决定。页面通过 `sitePetInteraction` 注入槽将会话借给全局 pet；`SitePetGameBubble.vue` 只展示状态并转发操作，页面仍负责取消请求与释放会话。离开五子棋后 pet 恢复网站使用向导。

复用浏览器中的 Room 模型设置，不新增密钥或改变原设置。加载页面不请求模型；用户落子后、请求提示/悔棋/开局时可触发一次回应，可关闭“落子时回应”。模型未配置或失败时显示明确状态，不以预设台词冒充模型。聊天消耗所选模型额度。每次最多参考 8 轮已完成对话，输入 500 字符，输出预算不超过 1024 token（保留用户更低上限及协议映射），45 秒超时。停止、下一步落子、悔棋、重开、离页、账号或模型切换会取消旧请求，旧回复不能覆盖新局面；重开或身份变化清空游戏聊天。

界面支持中文、英语和日语。聊天仅保留在当前游戏页面内存，不写入 Room 历史、长期记忆、日记或好感度；模型服务仍按其既有配置处理请求。棋盘使用网站的季节色和明暗主题变量。

界面支持选先后手、两种难度、提示、整回合悔棋和重新开始。设置只在新一局生效；进行中的棋局重新开始前会提示确认。方向键移动棋盘焦点，Enter 或空格落子。棋盘始终居中，桌面棋盘面板上限 800px；设置与规则位于下方。互动使用全站唯一的右下角 `SitePet`，不再显示独立角色面板。自动回复在贴着 pet 的短气泡中显示，点击 pet 展开自由聊天、停止、重试与自动回应开关。气泡为非模态，不锁定页面滚动；可用关闭按钮、Escape 或再次点击 pet 收起，草稿保留到本次棋局页面离开或身份变化。

棋局只保存到当前浏览器的 `tsukuyomi.gomoku.v1`。保存格式含版本、玩家颜色、难度及落子序列，恢复时逐步验证合法性；损坏记录会被忽略。存储不可用时仍可对弈并显示提示。离开页面、悔棋或重新开局会取消待执行的对手回合；返回后按已保存序列恢复。进度不跨设备同步，不上传积分。

## 验证

```sh
npm run test:game
npm run test:frontend
node --test tests/seo-geo.test.js tests/frontend-site-knowledge.test.mjs tests/site-knowledge.test.cjs
npm run build:web
PW_CHANNEL=chrome npx playwright test tests/e2e/game-center.spec.js --workers=2
```

浏览器测试覆盖桌面 Chrome、Android 尺寸 Chrome、iPhone 尺寸 WebKit，包括中心入口、实际落子、键盘操作、取消延迟回合、先后手、胜负、存储损坏、续局、三种语言、深色模式及棋盘居中/正方形/落点不重叠。浏览器测试还验证唯一 pet、非模态气泡、展开/收起、保留草稿、切页恢复向导、气泡屏幕边界与棋盘中心不偏移。模型夹具覆盖真实 Room 请求格式、人物卡、棋局上下文、自由输入、取消和异常；纯服务测试验证分段流式渲染、超时、上下文上限和账号隔离。这些不代替真实供应商效果与额度验收。

辉夜快跑的浏览器回归使用隔离的准备就绪消息夹具，未运行原游戏媒体。原运行时的完整引擎验收仍使用 `tests/e2e/kaguya-ride.spec.js` 和其所需的本地资源。

海外部署需同步 `deploy/overseas-openresty.conf` 的游戏子路由白名单、`overseas-translation-service.py` 和旁置 `seo-pages-en.json`；只更新前端会导致子路由直接访问返回 404。更新配置前备份并执行 Nginx 配置校验。
