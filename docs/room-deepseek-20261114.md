# Room DeepSeek 应用接口

实现依据：[chat-demo](https://github.com/deepseek-ai/chat-demo)、[聊天应用指南](https://api-docs.deepseek.com/zh-cn/guides/build_a_chatbot/)、[2026-11-13 更新](https://api-docs.deepseek.com/zh-cn/news/news261113)。录音编码沿用示例的 MIT 实现，见 `docs/third-party/DeepSeek-chat-demo.txt`。

## 用户路径

Room 设置 → 聊天模型，选择自己的 DeepSeek（`deepseek-flash`），或在“站内直供”选择同名模型。自己的官方接口支持浏览器直连和受限代理；第三方兼容网关须主动勾选“支持 DeepSeek 应用接口”，并使用直连。网关必须自己提供文件、搜索、OCR、ASR 路由，不能仅有旧聊天协议。

对话工具栏包含深度思考、联网搜索、阅读链接、文件、OCR、语音输入。语音最长 120 秒，编码为 16 kHz 单声道 PCM WAV，停止后转写到草稿，用户确认发送。OCR 同样只写入草稿。原 TTS、Live2D、四季场景、人设、记忆、日记与旧模型路径保留。手机聊天面板和消息底色透明，输入栏仍可清楚辨认。

流式适配处理思考、正文、服务端工具事件、最终来源、标题、签名网页上下文和用量；中断不自动重试。被安全检查拒绝的内容不作为成功回复保存，长度截断有明确标记。文件和来源随账号范围内的云端会话保存，切换供应商不携带旧文件或签名。迁移 059 仅新增 `provider_context` 列。

## 文件与费用

站内与代理上传单个文件最多 8 MiB，直接连接 DeepSeek 支持服务商限额（一般文档 100 MiB，ASR 8 MiB）。每轮最多 5 个附件。普通文档使用 `text_recognition`：实测相同 PDF 的 `rich_layout_recognition` 上传成功但聊天读取为空，普通文字解析可以正确引用。

站内文档先调用 OCR 获得明确的 `page_count`，再免费保存为 `user_data` 文字文件。这样按真实页数结算，不推算页数；文件中的图形不能经此文字转换保留，图片内容请单独作为图片发送。若 OCR 已完成而后续保存失败，已发生的 OCR 用量仍会记账；没有自动重试或第二次 OCR 调用。

工具费使用供应商基准价 × 11/10，与现有 10% 加价比例一致。聊天 Token 使用已公布的售价，不再乘一次倍率。2026-11-13 价格版本：搜索/抓取 ¥0.0055/次，OCR ¥0.00165/页，ASR ¥0.429/小时，按整秒向上取整。ASR 是供应商限时折扣，调价需更新服务端版本。

聊天默认预留 ¥1（可配置）；ASR 按 120 秒、OCR/文档按 1000 页、独立搜索/抓取按 1 次的服务上限预留，免费文件保存不预留。按最终用量结算并释放余款。聊天的 `max_tokens` 只限制每个生成步骤，不是多步整轮费用上限；超出预留或缺少最终用量须进入核对，不能伪装已结算或自动退款。

## 两个服务必须一起升级

1. 主站先更新钱包的 `deepseek-apps-v1` 价目合同、Room 后端/迁移和前端。
2. `tsu-api` 更新 `server/deepseek-apps.mjs`、同版本定价模块和配置/UI。
3. Terminal → 官方服务 → 语言模型，核对保留的 DeepSeek 密钥，设置 DeepSeek 对话与工具，工具倍率 11/10，三类 Token 售价 2.2 / 0.044 / 8.8 元每百万。默认不开放新服务；打开开关后与原站内模型并行提供。
4. Nginx/OpenResty 的实际响应头必须允许 `microphone=(self)`；仅修改 Node 头而边缘仍是 `microphone=()` 会阻止录音。上传路径的请求体上限需至少 12 MiB，SSE 禁止缓冲。
5. 必须核对当前站点登录、支付账单、真实设备麦克风权限和线上供应商响应，再宣称上线验收。

## 验证范围

真实供应商：ASR 正确转写约 3 秒测试录音；OCR 正确读取一页 PDF；原生文字/PDF 文件引用、OCR→文字文件→流式搜索链路均返回正确标题；搜索、抓取、引用、最终 Token 和计费工具次数返回有效。测试文件已删除；没有更改线上用户钱包或新功能开关。

本地隔离测试覆盖浏览器流式和刷新、云端上下文、文件归属、录音停止/退出清理、拒答、旧图片上传、输入法/键盘、统一钱包结算与幂等。浏览器录音生命周期使用模拟音频设备，不能替代真机 Safari/Android 麦克风验收。
