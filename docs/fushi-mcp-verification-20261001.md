网站入口 CDN 当前为全球；国内网站保留现有 SQLite、OAuth、通知、审核及回复事务。Fushi challenge/webhook 使用站长已批准的专用受限 SSH 出站通道，经现有海外服务器访问平台实际提供的回调目标。完整回调 URL、challenge、签名材料不写入本文或日志。
