# 四季主题

2026-10-06：春日樱花、夏夜花火、红叶月夜、雪夜灯语均已接入并完成本地验证。发布使用项目现有轻量双站流程。

## 使用

顶部账号菜单或移动端探索菜单 → **季节主题**，无需登录。可选择「自动跟随季节」或手动选择任一季节。浅色／暗色仍由原有按钮独立控制。

首次访问默认自动／北半球，按设备本地日期采用气象季节：北半球 3–5 月春季、6–8 月夏季、9–11 月秋季、12–2 月冬季；南半球相反。自动模式提供所在半球选择，不通过 IP 推断，不请求定位，也不调用外部服务。每个季节都使用自己的真实素材。

在本地午夜重新检查；从后台返回、页面恢复或窗口获得焦点时核对日期。只使用一个全应用定时器，没有每秒或每分钟轮询。跨夏令时的本地午夜同样处理。

偏好保存在当前浏览器 `localStorage.tsukuyomi_season_theme_v1`，同源标签页通过 `storage` 事件同步；不上传服务器、不写账号资料。清理浏览器数据后恢复默认。禁用存储或配额不足时，本次选择仍生效，面板提示未保存。

## 改动边界

季节只替换公共页面背景、大厅 Hero、缺省文章／图库／像素封面，以及有对应素材的导航预览。Wiki 书房和辉夜快跑继续使用各自功能专用图片。用户提供的封面始终优先。

原有页面布局、字体、配色、玫瑰色按钮、圆角和业务交互不变。Room Live2D、房间场景、音乐、入场视频、用户像素画数据和其他运行资源不变。没有后端、数据库或服务器配置改动。

`data-season` 表示实际展示的季节；`data-calendar-season` 表示设备日期对应季节；`data-theme` 继续表示 light/dark。季节 CSS 只覆盖背景图和 Hero 图片裁切位置，没有组件几何或颜色变量覆盖。

## 素材与负载

| 季节 | 素材目录 | 应用使用的五张 WebP 总大小 |
| --- | --- | --- |
| 春日樱花 | `src/frontend/assets/sakura/` | 沿用既有资源 |
| 夏夜花火 | `src/frontend/assets/seasons/summer-v1/` | 2,047,544 字节 |
| 红叶月夜 | `src/frontend/assets/seasons/autumn-v1/` | 2,098,326 字节 |
| 雪夜灯语 | `src/frontend/assets/seasons/winter-v1/` | 2,287,344 字节 |

夏、秋、冬各保留六张素材：浅色背景、同构图暗色背景、Hero 场景、真实透明 Hero、文章封面和像素风封面。由内置 imagegen 根据用户参考生成，不使用 CLI 或新增 API 凭证。季节服饰属于本次美术设计，不声明为原作服装设定。

不透明素材使用 WebP quality=90，透明素材用无损 WebP，保持原尺寸和原始 Alpha。透明 Hero 为备用素材，没有引入应用，避免与已使用的 Hero 场景重复下载。原始 PNG 保存在 `output/imagegen/<season>-v1/`。完整提示词、输入角色、尺寸、用途、SHA-256 见各目录 `prompts.json` 与 `manifest.json`。

应用资源由 Vite 生成内容哈希。图片 URL 的导入不等于下载；只在实际显示或既有导航预览需要时请求图片，没有四季素材全量预载。无需增加服务器进程、内存限制或数据库存储。
