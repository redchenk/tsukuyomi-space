## 已验证行为

- 参数值与字段映射分别按内置、供应商端点、模型覆盖；零值、关闭思考、继承和不发送均保留其含义。配置按端点与完整模型 ID 隔离，基础 URL 与规范化后的调用地址共享同一范围。
- Chat Completions、Responses、Messages、Ollama 使用各自允许的字段；任意请求头、消息、模型或原型路径不能作为映射。浏览器和后端都在出站前验证配置。
- 供应商没有明确能力字段时保留未知；模型级人工覆盖优先，目录刷新不会覆盖它。明确关闭图片、工具、文本或流式时遵守对应行为。
- 保存并重新进入设置后配置一致，真实前端聊天和诊断的出站参数一致。日记沿用同一参数解析器。
- 文本、流式、图片请求、工具调用与配对续轮分别测试。工具结果为本地固定值，不执行外部操作。一次性回复不能被标记为已验证流式。
- 代理内的供应商 401 显示为供应商失败，不把代理的外层 200 显示为成功。错误说明使用固定分类，上游原始错误不进入报告。
- 取消、超时与配置切换分别处理，旧响应不能恢复已清除的结果；下载报告不包含密钥、完整端点、请求内容、回复正文、图片或固定工具结果。
- Chrome 与移动 WebKit 的保存、聊天、图片选择、报告下载、工具协议、配置切换和英日语言切换通过；浅色和深色布局无水平溢出。
