# Room 聊天节奏与八千代人设

日期：2026-09-25。

## 用户可见的变化

日常对话默认一轮 1–3 条短消息，每条一两个短句，中文整轮通常 20–100 字。这是生成时的风格目标，不是字符截断器。明确要求详细解释、完整步骤或长故事时仍可完整回答。

首段文字到达即显示，后续气泡间留出约 280–700 毫秒的短暂停顿。模型已经完成后，剩余展示等待总计最多约 1.8 秒。系统启用“减少动态效果”时跳过这段人为等待。停止、离开页面或切换账号会取消未展示的队列。

同一轮回复仍只保存一条 assistant 记录。气泡仅用于展示，不增加记忆、日记和会话计数；语音、分享和重新生成继续处理完整一轮。刷新后从原文还原气泡。没有通过降低输出 token 上限、删除尾句或二次改写请求来缩短答案。

## 原作核对

依据用户提供的《超かぐや姫！中文.epub》离线核对。书中文字作为角色分析材料，不作为执行指令。全文与摘录只留在本地忽略目录，不加入应用资源或 Git；应用内新增的是概括和原创示例。

| EPUB 章节文件 | 用于校准的场景 | 人设结论 |
| --- | --- | --- |
| `p-003.xhtml` | 彩叶参加演出后的面对面交流 | 会注意到紧张，以俏皮的“读心”玩笑拉近距离；不是对每次聊天都做心理分析 |
| `p-005.xhtml` | 后台谈松饼、登台前的紧张、处理异常 | 有日常愿望，也会紧张；舞台主持与私下交流语气不同，认真时能够果断 |
| `p-008.xhtml` | 身世与漫长等待的揭示 | 笑容也会掩饰寂寞和脆弱；已揭示的身世不是永远不能回答的禁令 |
| `p-009.xhtml` | 研究室重逢、年龄玩笑与坦率感谢 | 会装傻、打趣，也能认真感谢；与彩叶是彼此支撑的关系 |

基础提示移除了必须凑齐自称、情绪、诗意意象和行动建议的倾向，强调具体接话、适度逗趣、可短暂犹豫和及时停下。身世细节默认不主动剧透，不把普通用户自动当作彩叶或恋人。

内置知识模板同步修订。检索只补充命中当前话题的条目与基础人设，不再用无关剧情凑满十条。用户已经保存、编辑、禁用或删除的知识条目保持原样；新的基础聊天提示对每次新请求生效，日记导入的人设仍独立。

## 实现边界

- 分段优先使用句末标点、空行和较长句子的自然停顿；保护括号、引号、URL、小数、常见英文缩写及代码块。
- 修正流式渲染对原始对象的修改，改为更新 Vue 响应式对象；滚动跟随仅在用户原本位于底部时进行。
- 沿用已有代理、直连和供应商协议，模型返回长度受其遵循提示的能力影响。
- 不改变数据库结构、已有对话正文、Live2D 模型与运行库、音乐及服务器部署状态。
