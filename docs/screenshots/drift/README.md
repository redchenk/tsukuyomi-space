# 星海来信界面展示

截图来自本分支的真实界面，使用隔离本机 API、SQLite 数据库和合成账号（海月、远舟）。没有使用真实用户的私密正文。图中时间由应用正常显示。

这些图片用于介绍功能，不作为历史手动测试或实体手机的验收证据。历史结果和接口记录仍保留在测试报告中。
