# Room 模型参数、能力与诊断

入口：`/room/settings` →「聊天模型」→「模型参数与能力」或「模型诊断工作台」。沿用当前浏览器的模型账号与密钥，不增加服务、依赖、数据库迁移或长期服务器凭证。参考 Halo AI Foundation 的分层配置设计，代码独立实现。

## 参数设置

「编辑范围」可选择当前供应商端点或当前模型。参数值与字段映射分别按 **内置 → 供应商 → 模型** 覆盖；留空或选择继承会恢复上一级。供应商按完整端点隔离，模型再按完整模型 ID 隔离。支持温度、Top P、最大输出 Token、推理强度和思考模式。

字段只能选当前协议允许的预定义路径，无法覆盖模型、消息、工具定义、请求头或密钥。例如 Chat Completions 可选择 `max_tokens` / `max_completion_tokens`，Responses 使用 `max_output_tokens`，Ollama 使用 `options.num_predict`。不发送会移除该参数；Messages 必需的最大输出字段不允许移除。推理模型默认不发送温度和 Top P；模型特有例外可手动配置并测试。

未配置参数时沿用原有请求默认值，不新增聊天回复长度限制。保存后，聊天、日记、朗读翻译和 Live2D 模型调用使用同一解析器。浏览器直连与后端代理都验证参数类型、范围与字段映射。配置保存在 `roomLLMSettings.runtimeConfig`，每类最多 64 个条目；代理只发送当前端点与模型的白名单配置。

参数值、映射来源可分别来自不同层级。例如供应商设置最大输出 4096，模型只覆盖为 `max_completion_tokens`，实际请求仍使用 4096。

官方字段参考：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[OpenAI Responses](https://developers.openai.com/api/reference/python/resources/responses/methods/create)、[阿里云 Qwen](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-openai-chat-completions)、[Ollama Chat](https://docs.ollama.com/api/chat)。通用参数范围不代表每个模型都接受，工作台用于检查当前模型实际行为。

## 能力来源与覆盖

文本、图片、工具、流式能力分别记录支持、不支持或未知。只使用目录明确返回的能力字段；默认填充的 `inputModalities: ['text']` 和模型名字不能作为“不支持图片”的证据。供应商声明优先于少量明确的内置声明，模型级人工覆盖优先级最高。

目录刷新不覆盖人工设置。人工选项「使用能力声明」恢复供应商或内置来源。保存当前模型时记录其目录声明，离开设置后的实际请求也能使用同一信息。来源不等于实测，工作台结果不会自动把单次成功升级成永久能力声明。

明确不支持图片时，普通聊天不会静默丢弃图片；自动模式可以使用已成功返回的 MCP 图片理解结果。不支持工具时普通聊天关闭工具循环；不支持流式时普通聊天使用一次性请求。未知能力保留原有可用调用方式。

## 诊断工作台

使用当前表单，不要求先保存。每次「开始模型测试」仅执行选中的项目：

- 文本：解析一次性回复。
- 流式：使用正常流式解码器，检查结束标记；一次性降级显示“未验证流式”。
- 图片：使用用户选取并压缩去元数据的图片。回复能返回只表示请求完成，识别正确性由用户检查。
- 工具：模型生成 `web_search` 参数，浏览器提供固定结果，再由模型继续回复。不开启外部 MCP 操作。

展示协议、请求方式、HTTP、响应格式、首段文字时间、总耗时、流事件数、用量、阶段与告警。代理返回经过白名单挑选的上游响应格式，避免把本站 SSE 包装误认为供应商使用流式。

测试可取消，最长 45 秒。切换模型、密钥、参数、项目或测试消息会取消旧测试并清除旧结果，旧响应不能覆盖当前表单。测试不写聊天、日记或长期记忆；回复预览仅留在当前组件内存中。

「下载脱敏诊断报告」不包含密钥、请求头、完整端点、测试消息、回复正文或图片。失败使用固定分类说明，不反射上游原始错误。测试使用用户自己选择的服务商，正常 API 计费规则仍由该服务商决定。

## 验证

`test:model-runtime` 覆盖分层映射、协议字段、能力来源、配置隔离、输入边界、后端出站前拒绝、工具续轮、取消及报告脱敏。`room-model-runtime.spec.js` 在 Chrome 与移动 WebKit 中验证设置保存、目录刷新、实际聊天参数、工作台、图片、工具、下载与旧响应隔离。真实模型账号、区域授权、识别正确性与实际性能由用户在工作台验收。
