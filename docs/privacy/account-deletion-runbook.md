# 月读空间账号注销处理流程

公开政策：`https://yachiyo.hk/privacy`。公开申请入口：`https://yachiyo.hk/delete-account`。
负责人：站长 redchenk，`redchenk919@gmail.com`。网站、Google Play 和其他原生版本共用账号与申请。

## 每日检查与时限

超级管理员进入「内容管理 → 注销申请」，每日检查待核验与处理中队列，以及隐私邮箱；优先处理逾期标记。在线提交会生成私有站内通知。以首次收到申请为起点，通常 30 日内完成。邮箱申请同样有效，不得要求重新安装 App、额外购买或放弃余额。无法按期处理时，在期限前通过已核验邮箱告知原因、需要的资料和预计日期，不得默默无限延期。

## 核验与清理

1. 点击「开始核验处理」。通过绑定邮箱确认请求人及删除范围；不可索取密码、验证码、API 密钥或不必要的证件。在线会话仅证明提交身份，不替代最终核验。
2. 在删除 users 行前建立受控清单：用户 ID、公开文章/评论/广场/图库/像素作品、附件存储键、聊天图片、日记、Room 历史/记忆、通知/社交/成长/游戏记录、OAuth/合作方授权、邮箱连接和会话、站内余额及独立 tsu-api 关联。清单仅站长可访问；不要复制正文、密码、密钥或 cookies。保持关联直到所有清理已验证，不能先置空作者再丢失查找依据。
3. 核对已支付未交付、余额、未结算请求及争议；与用户确认合法处理，不自动没收或退款。确有法定留存义务时，列明最少字段、目的、法律依据、明确截止日期，隔离访问。普通内容不得以财务留存为由继续公开。
4. 停止该账号正在进行的 AI/同步任务，撤销所有会话、OAuth/合作方 token、邮箱连接和相关后台任务，阻止并发恢复数据。
5. 清理本机 SQL 各关联表；同时处理公开作品/回复正文的个人信息、附件/缩略图、OSS 对象及历史版本、CDN、向量库/Milvus/Mem0、独立 API/wallet 服务和受托处理方。单纯执行旧 deleteUser 只会解除部分作者关联，不等于完成删除。第三方公开转发副本不在本站直接控制范围内，应告知用户并提供协助。
6. 处理主站、海外节点、对象存储及人工运维备份。不能立即清除的副本必须限制访问并登记清除日期及依据；任何恢复流程上线前，重新应用未到期的删除清单，验证账号及内容没有复活。不要为了一个申请无差别销毁其他用户的备份。
7. 向核验邮箱发送处理结果，逐项说明删除或不可逆匿名化范围，以及必须留存的类别、原因、期限和申诉方式。请用户清除其各设备缓存、导出和第三方自存文件。
8. 只有账号行已删除（申请 user_id 自动置空）、清单全部核验、完成通知已送达后，才可「登记已核验完成」。工作台不会执行上述删除或发送邮件，不能用勾选替代实际操作。最终摘要不要含邮箱、身份证、正文或密钥。

## 留存与恢复验证

申请记录不复制用户邮箱；待处理时联表读取联系信息，账号删除后解除关联。仅保留最少申请编号、时间、政策版本、状态及不含敏感信息的处理摘要用于履约核验。对额外人工清单实施按目的最短留存；完成且无争议时销毁身份对应关系；确需备份恢复拦截的最少标识隔离保存至最后相关备份清除。复核恢复时必须运行删除清单，不能只恢复旧数据库。

演练只使用隔离数据库及虚拟用户、文件、余额；不得为验证入口删除真实账号或发起真实支付。每次发布检查公开 URL 无需登录可读，普通账号无法读取队列或他人申请，重复提交幂等，取消与开始处理互斥，完成前置条件有效。
