# Room 图片预览

登录用户发送图片时，浏览器先缩放并移除原图元数据，再上传到现有对象存储的 `room-private` 目录。每张图片最长边 1600px、最大 512KiB。应用服务器只短暂转发内存中的图片，不写本地文件；SQLite 和聊天同步只保存图片引用。图片明确使用私有对象 ACL，经登录账号校验后读取，不进入公开附件库或对话分享页。

访客图片保存在当前浏览器的 IndexedDB；登录账号的预览可跨设备读取。OSS 未配置或上传失败时保留待发送图片并显示错误，允许重试，不静默降级为文件名或公开上传。已丢失的旧图片仅有文件名，无法恢复。

新建对话会立即撤销旧图片访问并异步删除 OSS 对象；被聊天历史上限淘汰或上传后未完成的图片在 24 小时后回收。回收失败保留数据库记录，下次回收重试。

发布需要先备份数据库并应用增量迁移 038，再发布应用。迁移只添加空表和索引，不改写聊天或资源。回退代码时保留新增表，勿用旧数据库覆盖新聊天。
