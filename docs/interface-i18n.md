# 界面翻译与 Access 入口

界面支持中文、日文和英文。国内站沿用用户保存的语言选择，海外站仍固定使用英文。本次界面翻译不会读取或改写用户文章、评论、聊天、昵称、知识库、输入值和模型提示词。海外站原有 `/en-api` 公开内容翻译机制保持不变，与本地界面词典独立。

## 翻译维护

- 导航、登录等核心文案继续使用 `src/frontend/i18n/messages.js` 与 `messages.en.js`。
- 其他界面文案的英文、日文保存在 `src/frontend/i18n/interface-catalog.json`。中文原文是键；键首尾空白被去除，连续空白被合并。
- 动态提示使用 `{0}`、`{1}` 等参数，例如 `uiText('已更新 {0} 个聊天模型', [count])`。参数按原样替换，不作为翻译键，也不拼成 HTML。
- `scripts/i18n-transform.cjs` 在 Vite 构建时处理 Vue 模板文字、界面属性、标签和状态提示。它不遍历运行时 DOM，也不发送在线翻译请求。数据、常量、i18n 和运行时目录排除在转换之外；协议标识、分支条件、表单值、URL 和用户绑定保留原样。
- `scripts/i18n-plugin.mjs` 统一解析按语言拆分的词典模块。网站与独立 Live2D 调试页的构建入口均接入解析；调试页不额外改写自身模板。
- 对于作为内部分类标识使用的中文值，保持存储值与比较条件不变，只在显示位置调用 `uiText`。后台分组和房间设置分组是示例。
- API 的已知错误通过 `translateFeedback` 本地匹配。未知服务商错误保留原文，避免改变含义；这个错误匹配过程不发送外部翻译请求。

英文、日文词典各自构建为带哈希的独立模块，仅在需要时加载和缓存。中文访问不下载这两个词典。切换语言不重载页面，不清空草稿或 API 密钥。新增文案后补齐两种译文，运行 `npm run test:i18n` 和 `npm run test:frontend`，再构建国内与海外版本。更新词典后重启本地预览，核对实际按钮、占位提示和弹窗。

## Access 入口保障

视频与交互前景分层。进入按钮从页面渲染时即显示，不依赖播放成功、视频事件、浏览器焦点或首次触摸。视频播放失败时继续使用海报，入口保持可点击；异常进入原生全屏时退出全屏并回退海报。`pageshow` 恢复暂存的离场状态，防止 Safari 页面返回后留下透明或禁用的按钮。卸载时移除事件并取消导航定时器。

Access 首次挂载不等待附加语言词典；其他页面的词典下载异常也不会一直阻止页面挂载。已有视频渐变、手动暂停、减少动态效果和离场过渡保留。

## 验证

`tests/frontend-i18n.test.cjs` 检查构建提取的界面文案翻译、参数一致性、Vue/JavaScript 编译、协议与用户内容保护、核心词典键一致性。

`tests/frontend-access.test.cjs` 检查自动播放失败、页面返回、原生全屏回退、重复进入以及事件/定时器清理。

`tests/e2e/access-i18n.spec.js` 覆盖桌面 Chrome 和移动端 WebKit：无触摸的入口、短屏与横屏、视频失败、语言文件失败、页面返回、公共/登录后页面、后台分区，以及语言切换后草稿与用户知识原文保留。WebKit 仿真不能替代受影响的实体 iPhone 验收；原先的间歇性现象未在仿真环境稳定复现。

## 发布与回滚

使用项目现有前端发布流程，国内与海外站分别构建。没有数据库迁移、新服务、翻译 API 或新凭证。发布文件包含构建输出及哈希词典，旧页面使用的哈希文件按现有发布策略保留。回滚时恢复上一版前端构建及对应源代码，无需改动数据库或用户保存的语言设置。
