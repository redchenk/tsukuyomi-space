# 水镜回廊 · 视频 2 的朱红鸟居版

- `water-mirror-enter.mp4` 使用 UpDream Seedance 2.5 以视频 2 为底片生成的 1080p 正片。原片的回眸、伸手、推镜、朱红鸟居和少量飘樱保留在成片。穿过鸟居后，镜头沿原来的月面中心继续推进，约 6.04 秒处停在满月近景。近景补入了现有月面素材的细节。
- `water-mirror-standby.mp4` 使用 UpDream 对 Seedance 2.5 待机片的高清超分。首尾使用入场片同一帧对齐。
- `water-mirror-poster.webp` 取自入场锚帧，用于初次显示、减少动态和媒体故障。

两段视频均为 1920×1080、24 fps、H.264 MP4，无音轨。检测到第一帧解码后短暂淡接两段视频，满月近景之后用月光遮罩揭开大厅。
