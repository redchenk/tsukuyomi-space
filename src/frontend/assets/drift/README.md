# Mirror coast

`mirror-coast.webp` (pastel dusk) and `mirror-coast-night.webp` (meteor night)
are original AI-assisted fan landscapes for the Starlit Letters bottle shore.
They are not frames from the film. The page selects the matching image for
light or dark mode; no JavaScript theme-specific image loader is needed.

Visual references inspected during design:
- Cosmic Princess Kaguya's reflective lavender/rose sea and cumulus-cloud scene:
  https://fancaps.net/movies/Image.php?imageid=13744322
- Official Starfalling Sea MV announcement / cyan water-light reference:
  https://x.com/Cho_KaguyaHime/status/2001623485269921797

Composition: a broad open sky above quiet, low-horizon shallow water. The light
variant uses peach-pink clouds and lavender sky; the dark variant uses deep blue
clouds with a sparse meteor shower. A small distant torii and a few warm lanterns
remain near the right horizon. No characters, foreground lantern field or text
are embedded in the backgrounds. Bottle objects and controls are separate.

The current pair was created with the built-in `image_gen` tool, using the
operator's supplied film stills as references for sky color, clouds and meteor
trails. Screenshot chrome, logos, watermarks and characters were not used in
the delivery composition. Water reflections are subdued and diffuse. The WebP
files only change the encoding for web delivery (quality 88).

Exact final prompts and generated-master filenames are recorded in
[prompts.json](prompts.json). Masters remain in the local generated-image archive;
only the delivery assets are required at runtime.
