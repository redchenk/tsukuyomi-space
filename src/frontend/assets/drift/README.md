# Mirror coast

`mirror-coast.webp` is an original AI-assisted fan landscape created for the
Tsukuyomi Space bottle shore. It is not a frame from the film.

Visual references inspected during design:
- Cosmic Princess Kaguya's reflective lavender/rose sea and cumulus-cloud scene:
  https://fancaps.net/movies/Image.php?imageid=13744322
- Official Starfalling Sea MV announcement / cyan water-light reference:
  https://x.com/Cho_KaguyaHime/status/2001623485269921797

Composition: standing on the shore looking out, a quiet near shoreline, a low
horizon, soft blue/lilac/pink clouds reflected in calm water. No characters or
text are embedded in the background. Bottle objects and controls are separate.

Original generated master is retained in the execution workspace under
`/workspace/generated_images/exec-f9585801-7a08-44b0-addd-09b82d45ec09.png`.
The WebP only changes the file encoding for web delivery.
