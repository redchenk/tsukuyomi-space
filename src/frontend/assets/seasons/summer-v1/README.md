# 夏夜花火 · 夏季素材 v1

2026-10-05 使用内置 imagegen，根据用户提供的夏季页面参考生成。2026-10-06 已接入网站季节主题并完成本地验证，采用轻量双站发布。操作与自动切换规则见 [季节主题说明](../../../../../docs/season-themes.md)。

现有 `assets/sakura/` 继续作为春季主题保留。季节（春夏秋冬）与浅色/暗色是两个独立维度；自动季节和手动选择使用相同的素材映射，不改变已有导航、圆角按钮和业务功能。秋季「红叶月夜」与冬季「雪夜灯语」均已制作并接入，各季使用自己的素材。

设计元素：绣球花、绿叶、月夜湖面、烟花、灯笼和风铃；延续八千代银白长发、双环发饰、红纸伞及粉色章鱼玩偶。蓝白绣球浴衣是本次夏季美术设计，不是原作服装设定声明。

浅色与暗色版本是同一地点、同一构图。页面可分别叠加月白或深靛遮罩来保证文字可读，遮罩用 CSS 实现，不烘焙进图片。沿用现有玫瑰色按钮。Hero 场景桌面建议 `object-position: 72% top`，手机建议 `75% center`，封面人物建议 `right center`。

网页文件合计 3,313,134 字节；五张不透明图为 WebP quality=90，透明图为 lossless WebP。保留原尺寸，透明图 Alpha 与原始 PNG 逐字节相同。`manifest.json` 包含用途、尺寸及 SHA-256。按当前路由载入所需图片，避免同时预载六张或全部四季资源。

完整提示词和输入角色记录见 `prompts.json`。原始 PNG 位于工作区 `output/imagegen/summer-v1/`；未覆盖既有素材。`preview.html` 是独立素材预览，浅色/暗色按钮只作用于预览。网站使用 Hero 场景，因此透明 Hero 备用图未引入应用构建，避免重复下载。
