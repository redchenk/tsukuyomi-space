# 四季导航纹样

依据 `design-assets/navigation-seasons-v1/` 中选定的连续圆角导航方案，由内置 imagegen 生成独立透明纹样。原始 RGBA PNG、无修改提示词以及供网站加载的 WebP 都保存在本目录；来源、尺寸、透明通道与 SHA-256 见 `manifest.json`。

春：樱花与月牙；夏：绣球与绿叶；秋：枫叶与桂花；冬：梅枝与雪花。

`styles/navigation-art.css` 根据现有 `html[data-season]` 选择纹样，在导航栏和菜单上下边缘绘制。中间遮罩减淡花纹，装饰层不接收鼠标事件；磨砂玻璃由实际 CSS 材质实现，浅色遮盖率 76%、深色 84%，标准模式模糊 22px。低性能模式仅顶部导航保留 8px 轻量磨砂、84% 遮盖率，其余导航浮层使用 92% 遮盖率；减少透明度、强制色彩和不支持模糊的环境保留实色回退。手动季节切换先准备对应素材，再执行 650ms 页面淡化过渡，遵守系统减少动态效果设置。

运行时仅使用 WebP；四张合计约 740 KiB，浏览器只绘制当前季节引用的图片。PNG 作为可再编辑源文件保留。低性能、减少透明度、无 backdrop-filter 支持时使用实色材质；高对比模式隐藏纹样。
