# 邮件内嵌素材

- `sakura-logo-v1.png`：现有网站 `src/frontend/assets/sakura/sakura-moon-logo.webp` 的 PNG 邮箱兼容版，128 × 128。
- `sakura-banner-v1.jpg`：从用户确认的月白樱粉邮件预览中，使用内置 imagegen 提取的无文字横幅，JPEG 邮箱兼容版，900 × 363。

原始生成提示：从确认的邮件预览中仅提取月夜樱花与八千代横幅，保留人物、纸伞、粉色玩偶、湖畔和月亮，去除全部邮件文字及外框，生成无文字矩形横幅。最终编码仅调整尺寸与压缩，不改变构图。

两张图通过 MIME 的 CID 内嵌到所有网站自动邮件中，不对收件人发起外部图片请求。不要把完整设计预览或文字验证码烘焙成图片；所有邮件文字应由模板实时生成。
