离线编码仅调整尺寸与压缩。两张图合计约 45.6 KiB；logo 上限 16 KiB、横幅上限 36 KiB，超过预算会拒绝构建邮件。旧的 v1 素材已从项目移除。

两张图通过 MIME 的 CID 内嵌到所有网站自动邮件中，不对收件人发起外部图片请求。不要把完整设计预览或文字验证码烘焙成图片；所有邮件文字应由模板实时生成。
